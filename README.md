# Rega Fácil

App Android (Expo / React Native) — assistente para cuidar de plantas.

## Rodar no Android

```bash
cd D:\React-Native\jardim-copiloto
npm run android
```

Ou `npm start` e pressione `a` / escaneie o QR no **Expo Go**.

## O que tem no piloto

- Cadastro de plantas (foto, rega, adubo)
- Alertas locais
- Notas, histórico e modo escuro
- Políticas de privacidade / termos
- Banners de anúncio (teste)
